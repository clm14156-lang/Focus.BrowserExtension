# Chrome / Edge 完整功能验收

自动测试命令及演示模式见 README。以下每项在 Chrome 和 Edge 分别执行；记录浏览器版本、桌面端版本、Windows 用户、时间、结果及延迟。测试前关闭模拟 Host，确认弹窗没有“演示”标识。不要使用 DevTools 始终打开的单次结果代替后台休眠验收。

## 真实链路（必须先通过）

1. 真实 `--probe-service` 成功，核对阶段及 domainCount。
2. WPF 配置启用 `example.com`（名称“示例网站”）及一个禁用网站；开始普通专注。记录 WPF Focusing、Host 采样、插件 applied sequence、首次成功重定向的时间。常规负载目标在变更后 1 秒左右，校准路径可能约 5 秒；记录实际值，不宣称平台实时保证。
3. 提示页名称为“示例网站”，域名正确，图标加载或显示本地字母图标，倒计时推进且明确标注估计值。弹窗与 WPF 粗略剩余时间相符。
4. 分别验证放弃、提前结束和自然结束。确认规则删除、桌面网站保护变为 inactive 后，拦截页无需点击即可自动返回该域名的 HTTPS 首页；多个拦截标签页分别返回自身网站。Completed 历史不重新激活。WPF 代理若仍返回 403，应按系统代理问题排查。

## 状态、名单及匹配

| 场景 | 检查 |
| --- | --- |
| 普通准备的 5 秒 | 不宣称能从 IPC 得到完整准备态；不提前安装插件规则 |
| 普通 runtime Idle、BlockingEnabled false | 持久化 Focusing + 网站保护激活仍能屏蔽 |
| 普通名单实时修改 / 禁用 / 全空 | 及时替换，禁用项不拦截，空列表无规则 |
| 强制 Preparing → Focusing → 完成 | 准备不拦截，正式开始按快照拦截，结束清理 |
| 强制期间修改全局名单 | 仍使用该会话快照，名称也来自快照 |
| 强制缺失快照 / 多个活动会话 / 无效时间 | 明确错误，不回退全局名单，不冒充已同步 |
| `example.com` / `a.example.com` | 自身和子域命中 |
| `notexample.com` / `example.com.evil.test` | 不命中 |
| 更具体子域配置另一个名称 | 显示最长匹配域名对应名称 |
| 大写、www、IDN、端口、路径、查询 | Core 规范化，提示页不携带原路径/查询/凭据 |
| 尾点、IP、localhost、file/ftp | 不擅自扩大 Core 支持范围，记录浏览器规范化边界 |
| PAC 冲突 / ProxyConflict / Faulted / 应用保护独有效 | 显示真实桌面健康状态，mirror 模式不新启用网站规则 |

## 生命周期及失败

| 场景 | 检查 |
| --- | --- |
| 未安装 Host / 错误 ID / origin | 显示 Native 错误，无规则，无假空闲/假成功 |
| WPF 关闭但 Service 强制专注仍进行 | 插件继续反映 Service 状态，不自行结束 |
| Host 退出 / Service 停止 | 可见失联，最多 10 秒目标且受原截止约束；重连退避无紧密循环 |
| Service 重启 / 强制恢复 | 新 epoch 全量同步；普通残留不自动恢复保护 |
| 通信存在但推送和响应都卡住 | 请求超时、租期清理、失败可见 |
| 浏览器完全退出后重开 | session rules / storage.session 失效，重新握手再安装 |
| 手动终止后台 / 扩展重载更新 | 旧规则有效期校验，缓存不延长原断线截止 |
| 睡眠后越过结束时间再唤醒 | 后台恢复后清理；记录延迟，不能承诺睡眠中秒级清理 |
| 时钟前拨 / 回拨 | 明显跳变使旧规则失效、重新采样；估计时间边界可见 |
| 撤销网站权限 / 模拟 DNR 更新拒绝 | 应用失败与实际旧应用序号可见，恢复权限后可重试 |
| 清理 API 失败 | CLEAR_FAILED 可见，后续触发重试，不宣称规则已成功移除 |
| 自动返回边界 | 断线清理、本地倒计时归零、仍在专注时移除一个域名均不触发自动返回；保护 deactivating 时等待 inactive |
| 畸形帧、错误版本、写方法、每秒超 10 请求 | 拒绝，无写透传；stdout 不混入日志 |
| 1001 个域名 / 外部 256 KiB / 内部 1 MiB | 明确超限/读取失败，无半套规则或静默截断 |
| 多 Profile / Chrome+Edge / 多 Windows 用户 | 同用户同策略，异用户 SID 隔离，不抢 Agent 代理动作 |

浏览器完全退出测试时，注意 Chrome/Edge 的后台应用和启动加速可能使进程仍存活。使用独立测试 Profile，确认进程已退出，避免误报 session rules 的清理行为。

## 页面与覆盖边界

验证窄屏、长名称、无 favicon、页面后台再恢复时的倒计时；结束后前台自动返回，后台标签页在浏览器调度或恢复可见时自动返回。名称包含 HTML 字符只应显示文本。网页手动打开公开提示页或伪造 fragment，不应读到整套名单或任意调用 Native Host。提示页请求 popup 的全局状态应被拒绝。

保留记录：已打开页面、XHR/iframe、下载、WebSocket、站点 Service Worker/CacheStorage、隐私模式未授权。这些不属于本 MVP 的 main_frame 导航承诺。禁用/卸载扩展也可绕过插件，不代表强制软件保护被替代。
